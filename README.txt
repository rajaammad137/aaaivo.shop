AAAIVO.SHOP — Web Technology Assignment #1 (CLO1)
================================================

HOW TO RUN
1. Extract the ZIP file.
2. Open the AAAIVO_SHOP_Assignment folder in VS Code.
3. Start the website with Live Server by opening index.html.
4. Internet is required for Bootstrap and Google Fonts CDNs. Product images and project files are local.

PAGES
- index.html: Home page
- about.html: About page
- products.html: Product catalogue, search, category filters and sorting
- product.html: Individual product details, Add to Bag and Buy Now
- checkout.html: Delivery form, order summary, Cash on Delivery and demo debit/credit card option
- contact.html: Contact form and FAQs
- css/style.css: Main stylesheet and responsive layouts
- js/app.js: Search, product rendering, cart, checkout and demo form interactions
- images/: Local SVG product illustrations

FUNCTIONALITY
- Header search opens on all main pages and sends the search term to the product catalogue.
- Clicking a product opens its individual details page.
- Add to Bag, Buy Now, cart quantity controls and subtotal work in the browser.
- Cart contents are saved in localStorage and remain available while using the same browser.
- Checkout page displays products, subtotal, sample delivery fee and total.
- Cash on Delivery is available as the default payment option.
- Debit / Credit Card is shown as a demonstration option only.
- Submitting checkout displays a local demo order confirmation.
- Newsletter and contact forms show on-page demo confirmations.

IMPORTANT PROJECT LIMITATIONS
This is a front-end academic demonstration. No real order is sent to a store, no payment is processed, and no card details are transmitted or stored. A production shop would need a secure backend, database, order management and a PCI-compliant payment gateway. Do not enter real card details in the demo form.
